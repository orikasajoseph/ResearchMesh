## 怎么逐项验证

在 ResearchMesh 文件夹打开终端，运行 `python -X utf8 verify_project.py`。
成功后会生成新的 `outputs/acceptance-时间戳/`，包含测试原始输出、HTTP 返回证据和五个演示场景。
不会覆盖旧记录，也不会保留测试服务进程。

| 验证部分 | 通过标准 |
|---|---|
| 数据格式 | 三个样例符合 Pydantic 与 Schema；未知字段及不正确类型被拒绝 |
| 规划容错 | 第一次不合法、第二次合法则成功；两次错误则失败；超时不编造计划 |
| 本地接口 | 健康和已知样例返回 200；未收录问题返回 409；空/错误输入返回 422 |
| 正常闭环 | S1 完成后 S2/S3 并发，三个结果保留 |
| 故障隔离 | S2 失败不丢 S1/S3；S1 失败则跳过 S2/S3 |
| 模糊需求 | 仅给追问，不执行科研任务 |
| 标识边界 | API、模拟结果和报告明确标注 fixture/local-mock/demoOnly |

测试全部通过只能证明本地框架有效，不能代替真实模型、真实科研 Agent、平台发现与 AIP 验收。
