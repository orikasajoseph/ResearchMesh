## 根因与修复

- 单入口将记录置于 `outputs/aip-research-时间戳/literature` 和 `reader`，旧 Literature Partner、Reader Partner、Reader Worker 仅允许 outputs 的直接子目录，导致真实检索前就启动失败。
- 统一由 aip_record_paths.py 校验：兼容旧目录及单入口的对应两种阶段目录；拒绝 outputs 根、pdf-cache、错误嵌套、越界及解析后落到外部的链接路径，不关闭安全保护。
- pipeline_failure.json 与终端显示自身安全阶段错误码，而不只显示 ValueError；不输出模型原始异常或 Key。
- 完整回归发现旧 run_deepseek_planner.py 的时间戳目录在同一时钟刻度可能碰撞。追加随机后缀、增加固定时钟测试，保留旧记录不覆盖。
- 单入口报告区分“执行链完成”与历史证据汇总，并明确是否复用 Planner 计划；不宣称正式平台已验收。
